Order History is a **Catalog route**. Use either:

```kotlin
FeatureRoute.Catalog.History()
// or My Space with History tab
FeatureRoute.Catalog.MySpace(
    defaultSelectedTab = FeatureRoute.Catalog.MySpace.MySpaceTab.History
)
```
