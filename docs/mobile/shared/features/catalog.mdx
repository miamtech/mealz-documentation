The catalog is a WebView journey driven by `FeatureRoute.Catalog`. Host UX (categories, preferences, favorites entry points, basket CTA, …) matches Mealz SSR.

:::info SSR
In-WebView behaviour: [Recipe catalog (SSR)](/docs/web_ssr/main-features/recipe-catalog).  
Events: [Analytics](/docs/web_ssr/analytics) (`category.display`, `preferences.display`, `liked.display`, `basket.display`, …).
:::

## Parameters

There is a **single** catalog entry point. You choose the starting page with `route`.

| Parameter | Type | Required | Default | What it does |
|-----------|------|----------|---------|--------------|
| `route` | `FeatureRoute.Catalog` | no | `FeatureRoute.Catalog.Home()` | Which catalog surface to open first (home, category, favorites, …). |
| `navigationCallback` | `CatalogNavigationCallback` | yes | — | How Mealz hands control back to your app (login, store, cart, exit, optional planner / home). |
| `modifier` | Compose `Modifier` | no | fills max size | Layout (Compose / KMM). |
| `stateContent` | screen state overlays | no | library default | Optional loading / error UI while the WebView boots. |

### `FeatureRoute.Catalog` variants

| Route | Parameters | Use when |
|-------|------------|----------|
| `Home(displayVariant?)` | optional recipe-card variant | Default catalog landing (categories). |
| `Category(categoryId, title, displayVariant?)` | Mealz category id + title shown in UI | Deep-link / open one category. |
| `List(displayVariant?)` | — | Recipe list (e.g. search results shell). |
| `MySpace(defaultSelectedTab?, displayVariant?)` | `MySpaceTab.Favorites` or `History` | My Space with optional default tab. |
| `Favorites(displayVariant?)` | — | Favorites as root (wraps My Space favorites). |
| `History(displayVariant?)` | — | Order history as root. |
| `MyMeals(showTabSelector, defaultSelectedTab?, basketTransferUrl?)` | see My Meals (Catalog journeys below) | Meals / products in basket. |

`displayVariant` (optional `Int`) selects the recipe-card visual variant inside catalog lists where supported.

### `CatalogNavigationCallback`

| Callback | Required | What you must do |
|----------|----------|------------------|
| `redirectToLogIn` | yes | Open your login when Mealz needs an authenticated user. |
| `redirectToStoreLocator` | yes | Open your store picker when no store is selected (retailer). |
| `redirectToCart` | yes | Open your retailer cart / checkout. |
| `exit` | yes | Dismiss / pop the Mealz catalog screen. |
| `goToPlanner` | no | Open the Mealz planner journey if the catalog CTA is used. |
| `goToHomeCatalog` | no | Navigate to catalog home when a **sub-route** (My Meals, My Space, …) is shown as root and asks to go home. |

## Inject

export function CatalogInject(props) {
  if (props.platform === "android") {
    return (
      <pre><code className="language-kotlin">{`CatalogScreenView.View(
    route = FeatureRoute.Catalog.Home(),
    navigationCallback = CatalogNavigationCallback(
        redirectToLogIn = { /* open login */ },
        redirectToStoreLocator = { /* open store picker */ },
        redirectToCart = { /* open retailer cart */ },
        exit = { /* pop screen */ },
        goToPlanner = { /* optional: open planner */ },
        goToHomeCatalog = { /* optional: when sub-feature is root */ },
    )
)`}</code></pre>
    );
  }
  if (props.platform === "ios") {
    return (
      <pre><code className="language-swift">{`CatalogViewController.companion.get(
    route: FeatureRoute.Catalog.Home(),
    navigationCallback: CatalogNavigationCallback(
        redirectToLogIn: { /* open login */ },
        redirectToStoreLocator: { /* open store picker */ },
        redirectToCart: { /* open retailer cart */ },
        exit: { /* dismiss */ },
        goToPlanner: { /* optional */ },
        goToHomeCatalog: { /* optional */ }
    )
)`}</code></pre>
    );
  }
  return (
    <pre><code className="language-kotlin">{`CatalogScreen(
    route = FeatureRoute.Catalog.Home(),
    navigationCallback = CatalogNavigationCallback(
        redirectToLogIn = { },
        redirectToStoreLocator = { },
        redirectToCart = { },
        exit = { },
        goToPlanner = { },
        goToHomeCatalog = { },
    )
)`}</code></pre>
  );
}

<CatalogInject platform={props.platform}/>

## Catalog journeys

Same entry point — only `route` changes:

export function RelatedCatalogSurfaces(props) {
  const base = `/docs/${props.platform}/features/catalog`;
  return (
    <ul>
      <li><Link to={`${base}/favorites`}>Favorites</Link></li>
      <li><Link to={`${base}/my-space`}>My Space</Link></li>
      <li><Link to={`${base}/myMeals`}>My Meals</Link></li>
      <li><Link to={`${base}/order-history`}>Order history</Link></li>
    </ul>
  );
}

<RelatedCatalogSurfaces platform={props.platform}/>
