My Space is a **Catalog route**. Use the same catalog entry with:

```kotlin
FeatureRoute.Catalog.MySpace(
    defaultSelectedTab = FeatureRoute.Catalog.MySpace.MySpaceTab.Favorites // or History
)
```

## Parameters

Same as Catalog (`route` + `CatalogNavigationCallback`) — see the Catalog link below. Route-specific:

| Route field | Type | Required | Default | What it does |
|-------------|------|----------|---------|--------------|
| `defaultSelectedTab` | `MySpaceTab?` (`Favorites` / `History`) | no | `null` (library default tab) | Which My Space tab opens first. |
| `displayVariant` | `Int?` | no | `null` | Recipe-card variant in lists. |

Set `goToHomeCatalog` when My Space is the **root** screen: the WebView may ask to open the main catalog (e.g. no liked recipes → browse the catalog). See Catalog docs for `goToHomeCatalog`.
