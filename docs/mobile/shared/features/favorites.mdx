Favorites is a **Catalog route**, not a separate native module. Use the same catalog entry with:

```kotlin
FeatureRoute.Catalog.Favorites(displayVariant = null)
```

:::info SSR
Catalog analytics include `liked.display` — see [Analytics (SSR)](/docs/web_ssr/analytics). In-WebView catalog: [Recipe catalog (SSR)](/docs/web_ssr/main-features/recipe-catalog).
:::

## Parameters

Same as Catalog (`route` + `CatalogNavigationCallback`) — see the Catalog link below. Route-specific:

| Route field | Type | Required | Default | What it does |
|-------------|------|----------|---------|--------------|
| `displayVariant` | `Int?` | no | `null` | Recipe-card variant inside the favorites list. |

Set `goToHomeCatalog` when Favorites is presented as a **root** screen: the WebView may ask to open the main catalog (e.g. empty favorites → browse recipes). See Catalog docs for `goToHomeCatalog`.
