# Implementation

## Implementing Mealz features into your website

Integrating Mealz into your website can be done in 3 steps:

1. Call the desired component route with the required parameters and [headers](../integration-reference/pre-rendered-components#http-request-headers) to retrieve the HTML, and then inject the returned content into the appropriate location on your website.
2. Set up client-side callbacks to synchronize Mealz with your website during runtime. Wire [basket synchronization](../set-up-and-usage/basket-synchronization) and [hooks](../set-up-and-usage/hooks).
3. [Customize the styling](../styling) of those components to match your site's design

For a guided walkthrough, start with [Getting started](../getting-started/overview). We cover each step in more detail throughout this documentation.
